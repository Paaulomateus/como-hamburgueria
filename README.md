# COMO Hamburgueria

Site da COMO Hamburgueria, em estilo fliperama (arcade, neon e pixel).

- `index.html`: a página inteira
- `assets/cardapio.js`: o cardápio. Para mudar um preço, troque o número depois de `"p"`
- `assets/`: vídeo do topo, logo e imagens

Não precisa instalar nada. A Vercel publica a pasta como está.
